# Source inventory

The holders Arrt reads images from, and the ones planned, on one page. This page is
a reference only. **The backlog is the source of truth.** Each backlog item holds
its holder's priority, measurements and disposition, and this page repeats none of
them. When the two disagree, the item is right; fix this page.

How a source plugin works is `docs/source-plugins.md`.
